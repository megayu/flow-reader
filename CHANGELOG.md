# Changelog

## [Unreleased]

## [0.1.3] - 2026-09-13

- Added previews for external links in books.
- Added a shortcut to reload the current book.
- Added support for translating release notes.
- Improved TXT import recognition and formatting.
- Improved performance in areas such as search, large TXT and dictionary imports, etc.
- Improved macOS and Linux compatibility in areas such as EPUB text editing, text selection, etc.
- Several bug fixes.
- Several minor UI improvements.

## [0.1.2] - 2026-09-09

- Added support for installed system fonts on macOS and Linux.
- Added error notifications when operations fail.
- Updated interface fonts to better match your operating system.
- Improved performance, especially when importing books.
- Several minor UI improvements.

## [0.1.1] - 2026-09-05

- Fixed the chapter search shortcut activating outside the reader.
- Improved highlights spanning multiple paragraphs by excluding surrounding whitespace.
- Improved body text detection for poorly structured EPUB books.
- Improved Linux and macOS compatibility.
- Improved performance in areas such as search, page turns, tab switching, etc.
- Several minor UI improvements.

## [0.1.0] - 2026-09-02

- Initial release.
